

## PetCare – Sistema de Gerenciamento de Petshop

O **PetCare** é um sistema web desenvolvido para gerenciar um petshop, permitindo **cadastro de usuários, pets e serviços**, com **login seguro** e **armazenamento de dados em nuvem**.

---

👉 [Clique aqui para acessar o PetCare-PetShop](https://mahvoid-404.github.io/PetCare--Petshop/)  

---
## Tecnologias Utilizadas

- **HTML5** – estrutura do site  
- **CSS3** – estilização e layout responsivo  
- **JavaScript** – funcionalidades e integração com o banco de dados  
- **Supabase** – autenticação e banco de dados em nuvem  
- **GitHub Pages** – hospedagem do site na web

---

## Hospedagem em Nuvem

O sistema está dividido em duas camadas:
- **Front-end** hospedado no [GitHub Pages](https://mahvoid-404.github.io/PetCare--Petshop/)  
- **Banco de dados e autenticação** hospedados no **Supabase** (serviço *Backend as a Service*)

Isso garante que o projeto funcione totalmente **nas nuvens**, com acesso remoto aos dados.

---

## Login e Autenticação

O sistema possui:
- **Cadastro de novos usuários** (nome, e-mail e senha)  
- **Login** com verificação via Supabase  
- **Validação** de credenciais antes do acesso ao sistema principal  

O login garante que apenas usuários registrados possam visualizar e manipular os dados.

---

## Cadastros Disponíveis

O sistema possui **três cadastros principais**, atendendo aos requisitos do projeto:

1. **Cadastro de Usuário**  
   - Criação de conta e autenticação via Supabase.  

2. **Cadastro de Pet**  
   - Informações como nome, raça, idade e dono.  
   - Permite listar, editar e excluir registros.  

3. **Cadastro de Serviço / Atendimento**  
   - Tipo de serviço (banho, tosa, vacina etc.), data e observações.  
   - Relaciona o serviço ao pet cadastrado.

---

## Funcionamento Resumido

1. O usuário se registra e faz login.  
2. Após o login, ele tem acesso às telas internas.  
3. Pode cadastrar, visualizar, editar ou excluir pets e serviços.  
4. Todas as informações são salvas automaticamente no **banco Supabase**, em nuvem.
